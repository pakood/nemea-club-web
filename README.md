# NEMEA CLUB · Sitio web interactivo

Sitio de demostración (Inicio, Planes, Sucursales, Servicios), responsivo y con animaciones.
HTML + CSS + JavaScript puros: no necesita instalar nada.

## Abrirlo en Visual Studio Code
1. Abre VS Code → Archivo → Abrir carpeta… → elige esta carpeta.
2. Acepta instalar la extensión recomendada **Live Server**.
3. Clic derecho en `index.html` → **Open with Live Server** (o botón "Go Live" abajo a la derecha).
4. Para ver la versión móvil: en el navegador, F12 → icono de dispositivos.

También funciona haciendo doble clic en `index.html` (requiere internet para las tipografías de Google Fonts).

## Compartirlo en línea (gratis)
- **Netlify Drop:** entra a https://app.netlify.com/drop y arrastra esta carpeta. Te da un enlace público.
- **GitHub Pages:** sube la carpeta a un repositorio → Settings → Pages → rama `main`, carpeta `/ (root)`.
- **Vercel:** `npx vercel` dentro de esta carpeta.

## Estructura
- `index.html` — contenido y logo
- `css/styles.css` — estilos y animaciones (colores en `:root`)
- `js/main.js` — datos (planes, clases, servicios, preguntas), navegación y botones

## Notas
- Tipografía Thunder sustituida por Bebas Neue; fotos son marcadores; domicilio y textos legales son de ejemplo.
